# EMPATHO — 유방암 검진 임상의사결정지원시스템(CDSS)

> AI가 판정을 대신하는 대신, **판정 근거를 보여주고 · 확신이 없으면 멈추고 · 최종 판단은 의료진에게 돌려주는** 유방암 검진 서비스
> 미래융합교육원 × 건양대학교병원 바이오메디컬 AI 과정 최종 프로젝트 (3조, 5인) · 2026.08 ~ 2026.09

🎬 **시연 영상** — 30초 소개 · 3분 기능 시연 *(링크 추가 예정)*

## 1. 풀려고 한 문제

| 현장의 문제 | 그대로 AI를 붙이면 생기는 문제 |
|---|---|
| 국내 40~69세 여성의 절반 이상이 치밀유방이고, 이때 맘모그래피 민감도가 크게 떨어진다 | 의사가 AI 숫자에 끌려간다 (앵커링·자동화 편향) |
| 경계 등급(BI-RADS 3 ↔ 4a)에서 판독자마다 판정이 갈린다 | AI가 틀릴 때도 똑같이 자신 있게 말한다 |
| 영상 판정 → 조직검사 → 병리 결과 → 추적관리가 부서마다 끊겨 있다 | 부서 사이의 공백은 모델 성능으로 메워지지 않는다 |

그래서 목표를 **"더 정확한 모델"이 아니라 "끊긴 진료 흐름을 잇고, AI를 안전하게 쓰게 하는 서비스"** 로 잡았습니다.

## 2. 사용자와 핵심 원칙

**사용자** — 환자(앱) · 원무/간호과 · 영상의학과 · 병리과 · 유방외과

| 원칙 | 화면에서 어떻게 보이나 |
|---|---|
| 근거를 보여준다 | 병변 마스크 · 판정 서술어 · 지표 카드 |
| 확신이 없으면 멈춘다 | 등급 대신 「판단 보류」 표시, 사람이 먼저 판정 |
| 병변 하나로 잇는다 | 영상 소견 → 검체 → 병리 결과가 같은 병변 아래 묶임 |
| 설명 후에 공개한다 | 환자 리포트는 대면 설명 뒤에 잠금 해제 |
| AI와 의사를 섞지 않는다 | AI 결과와 의사 판정을 따로 저장, 최종 결정은 의료진 |

## 3. 내가 한 일

### 기획
- **개인 문제정의서** — 병리 판독 불일치, 자동화 편향, "틀릴 것 같으면 멈춘다"(selective prediction) 근거 정리
- **검토 결정사항 정리** — 팀 합의를 **결정 27건 + 보완 8건**으로 문서화하고, 문서별 수정 위치 색인과 「이번 범위에서 결정하지 않는 것」 목록 작성
- **발표 구조 재설계** — PPT 피드백을 슬라이드별로 취합해 근거·권장안 정리, 25분 최종 발표 대본 작성
- **시연 영상 제작** — 30초 소개 영상, 기능 시연 영상, 나레이션 원고

## 4. 기획 결정 사례 — 문제 → 선택지 → 결정 → 결과

### ① 검체 연결 권한의 빈틈을 찾다
- **문제** 팀 합의는 "검체를 병변에 연결하는 권한 = 유방외과 + 간호과". 그런데 영상의학과가 직접 시행하는 영상유도 조직검사는 이 규칙에 막혀 병리 접수가 멈춘다.
- **선택지** ① 세 부서 모두 허용 ② 시술한 사람 + 간호과
- **결정** ① — 기존 합의를 가장 적게 바꾸면서 흐름이 끊기지 않는다.
- **결과** 권한표와 에러코드에 반영되고, 발표 자료 수정 근거로 쓰였다.

### ② "이번에 결정하지 않는 것"을 먼저 적다
- **문제** 시연용 프로토타입인데 운영 수준 항목(재시도·감사 배치·결제)까지 정하려다 일정이 밀리기 시작했다.
- **기준** "이게 없으면 시연 경로가 끊기는가? 발표의 주장이 무너지는가?"
- **결정** 모델 관리는 설정 파일로, 결제는 버튼까지만. 대신 **1차 판정 잠금 · 판단 보류 · 필수 연결**처럼 *나중에 넣으면 과거 기록을 되살릴 수 없는 것*은 반드시 넣는다.
- **결과** 범위를 줄이고도 핵심 주장은 지킬 수 있었다.

### ③ BI-RADS 0을 "의심"으로 뭉개지 않다
- **발견** 공개 데이터에서 판정 0 중 다수가 "가려져서 안 보임"이었다. 이건 "의심스럽다"가 아니라 **"다시 찍자"** 는 뜻이다.
- **결정** 등급에 섞지 않고 「추가 촬영」 칸을 따로 둔다.
- **결과** 추가 촬영으로 끝날 환자가 조직검사 경로로 밀려가지 않는다.

### ④ 발표를 "기능 소개"에서 "고친 문제"로
- **문제** 35장 중 15장이 화면 넘기기였고, "등급을 숨긴다"는 슬라이드에 등급이 보이는 모순도 있었다.
- **결정** 화면 슬라이드를 9장으로 줄이고, 제목을 기능명 대신 **고친 문제**로 바꿨다. 성능 주장과 설계 주장을 구분하고 「기존 경로가 끊기는 지점」 슬라이드를 새로 넣었다.

### ⑤ 현장 동선에 맞춘 권한과 화면
- 간호과가 실제로 원무 접수까지 맡는 흐름에 맞춰 **간호과에 원무 권한을 통합**
- 같은 환자·같은 날 **중복 예약 차단**, 예약 환자 접수 시 **중복 오더·노쇼 제거**
- 서버 문구를 화면 용어에 맞추고(「촉지 유도」→「위치 표지 유도」), 환자에게 풀려야 할 리포트가 의사용 사본에만 잠금 해제되던 문제를 수정

## 6. 한계를 먼저 밝힌 것

- 같은 환자의 영상·병리 짝 데이터가 공개돼 있지 않아 **모달리티마다 다른 코호트**를 썼고, 이를 화면과 발표에 명시했다.
- 모든 환자 데이터는 합성 데이터이며, 연구·교육 목적의 프로토타입이다.
